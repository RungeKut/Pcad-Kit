# P-CAD: схемы скриптами

Набор живёт в репозитории Pcad-Kit. Корень: переменная `PKIT_HOME`, иначе
junction `~/.kimi-code/skills/pcad` ведёт в `<корень>/skill`, а корень —
её родитель.

## Установка на новой машине

```powershell
powershell -ExecutionPolicy Bypass -File tools\setup.ps1
```

Скрипт создаёт junction `~/.kimi-code/skills/pcad` → `<корень>\skill`,
ставит `PKIT_HOME` в профиль пользователя, собирает `tools\dbx-host\DbxHost.exe`
(штатным `csc.exe` .NET Framework 4, `/platform:x86`) и прогоняет
дым-тест. Требования: P-CAD 2002 (`C:\Program Files (x86)\PCAD2002`),
Python 3.11+ любой разрядности.

## Первое действие

```python
import os, sys
sys.path.insert(0, os.environ["PKIT_HOME"])
import pkit as pk

pk.utf8_console()          # иначе print с кириллицей упадёт
print(pk.pcad_root())
```

## Два пути к схеме

| Путь | Когда | Чем |
|---|---|---|
| **пакетный** | чтение/правка файла .SCH; Sch.exe свободен | `pk.dump(path)`, `pk.open_design(path)` |
| **живой** | человек держит схему открытой в Sch.exe | `pk.dump_live()`, `pk.open_live()` — только чтение |

Ключевой факт архитектуры (`knowledge/10_API/10-01`): Dbx32.dll **не читает
файлы** — это DDE-клиент к запущенному редактору. Пакетный режим сам
запускает `Sch.exe <копия>` и гасит его по окончании.

## Минимальный рабочий цикл

```python
s = pk.dump(r"D:\проект\схема.SCH")   # копия, оригинал не трогается
print(s)                              # компоненты, цепи
for refdes in s.refdes():
    c = s.comp(refdes)
    print(refdes, c.type, c.value, c.attrs.get("ПЭ3", ""))
print(s.pin_nets())                   # {(refdes, pindes): netname}
```

Координаты в сырых данных — database units: 100000 на мм (`pk.sch.DB_PER_MM`),
перевод — `pk.Schematic.to_mm(v)`.

## Пять правил, нарушение которых стоит часа

1. **Только над копией в папке без пробелов и кириллицы.** P-CAD 2002 —
   ANSI-софт 2002 года. `pkit` копирует сам в `%LOCALAPPDATA%\Temp\pkit`.
2. **Пакетный режим — только когда Sch.exe не запущен.** DDE подключится к
   непредсказуемому экземпляру; если редактор открыт человеком — `dump_live`
   (чтение) или просить закрыть. `pkit` сам отказывает (`30_ГРАБЛИ/30-03`).
3. **Оригинал не перезаписывается.** `Session.save()` пишет копию задания,
   результат — `export_saved(новый_путь)`. В живом режиме save запрещён:
   чужой редактор сохраняет человек.
4. **Проверять числом и глазами.** После выгрузки сверять количества с
   ожиданием из независимого источника (отчёт, прошлая выгрузка), а не
   верить «0 компонентов» как правде (`TGetFirst*` на неправильном
   экземпляре молча даёт пустоту).
5. **Никогда не выдавать непроверенное за проверенное** — ни в коде, ни в
   отчёте, ни в базе знаний. Запись без `verified` силы не имеет.
