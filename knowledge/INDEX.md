## Быстрый поиск по симптому

* `DBX_CONNECTION_ERROR (32001)` / `DBX_NO_CONNECTION (32105)` — редактор не запущен или не открыл файл → 10-01, 30-03.
* «not a valid Win32 application» → 30-01.
* Выгрузилась чужая/пустая схема → 30-03.
* `isModified=1` без правок → 30-04.
* `MissingEndCurlyBrace` / «неожиданная лексема» в .ps1 → 30-05.
* `git push` отклонён с 403 / `Permission denied` → 40-02, «Вклад без права записи: pull request».
* `SSL certificate problem` / `511` при доступе к github.com → 40-02, «GitHub без gh» (прокси).
